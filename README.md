# TextRay AI Support

This public repository is the support and feedback tracker for the TextRay AI browser extension by MeetingScribes.

- [Report a bug](https://github.com/kmeelu1/TextRayAI-Support/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/kmeelu1/TextRayAI-Support/issues/new?template=feature_request.yml)
- [Read the privacy policy](https://textray-ai.meelu.chatgpt.site/privacy/)
- [Visit the product site](https://textray-ai.meelu.chatgpt.site/)

TextRay AI performs OCR locally in the browser. This tracker is public: never attach confidential documents, OCR output, screenshots containing personal information, access tokens, or other sensitive data. A sanitized reproduction and the browser/extension versions are usually enough to begin investigating.
